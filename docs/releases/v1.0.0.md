# Sonic 2 MD+ Forge v1.0.0

Released 2026-09-24.

This is the first production release of Sonic 2 MD+ Forge. It provides a
reproducible build system for creating the Addryu Mega-CD Remix MD+ build of
Sonic the Hedgehog 2.

The release contains tooling, configuration and documentation only. It does
not distribute the Sonic 2 ROM, Addryu's soundtrack, converted soundtrack
files, or a completed MD+ package.

## Hardware verification

The REV01 production build passed end-to-end testing on MiSTer FPGA, including:

- boot, title and menu behaviour;
- all 16 Addryu MD+ cues and loops;
- native sound effects alongside MD+ music;
- pause and unpause;
- temporary native music and return to MD+;
- invincibility and Super Sonic;
- boss music, drowning music and act completion;
- Special Stage transitions and return;
- two-player music;
- Level Select;
- Death Egg to ending transition;
- the shortened Sky Chase opening and its seamless shifted loop.

## Known issue

Issue #26 tracks an intermittent Special Stage results-screen text-corruption
incident observed once after obtaining the seventh Chaos Emerald.

Controlled REV00 and REV01 diagnostic builds did not reproduce the problem, and
there is currently no evidence that the issue is caused by REV01 or MD+.

See:

<https://github.com/lloydsmart/sonic2-mdplus-forge/issues/26>

## Building

Supply your own legally obtained Sonic 2 ROM and Addryu soundtrack files, then
follow the repository setup instructions.

The normal build stages are:

    make doctor
    make bootstrap
    make source
    make rom
    make audio
    make package

The completed local package is written beneath `dist/`.
