# Sonic 2 MD+ Forge v2.0.0

Release date: 2026-09-25.

Version 2.0.0 promotes the pinned current `sonicretro/s2disasm` REV01
implementation to the default production build. The generated ROM is the exact
Stage 5 image that passed the required MiSTer hardware gate. The previous
`msu-md-sonic2` implementation remains an explicit legacy fallback.

This release contains tooling, configuration and documentation only. It does
not distribute ROMs, upstream source/assets, Addryu audio, converted soundtrack
files, disc images or generated MiSTer packages. Users supply their own lawfully
obtained soundtrack files for local builds.

## Release architecture and commands

| Role | Source | Exact pinned commit |
| --- | --- | --- |
| Production | `sonicretro/s2disasm` | `380f37a731bfc720bb0371a35a593184a7ec5e43` |
| Explicit legacy fallback | `lloydsmart/msu-md-sonic2` | `b49afdb010090c282e1bb79f18f14a32d1bb7a99` |

Normal `bootstrap` fetches the production dependency into ignored
`build/source-modern/`. Production preparation and building use disposable
clones; dependency checkouts remain read-only inputs. Legacy preparation also
uses a disposable clone. Its ASL 1.42 build 306 dependency remains pinned to
`c7155b4fd3d33110f0eb098dede4295a8c008772`.

The complete default build is:

```sh
make doctor
make all INPUT_DIR="$PWD/inputs/audio"
```

The individual production stages are:

```sh
make bootstrap
make source
make rom
make audio INPUT_DIR="$PWD/inputs/audio"
make package
python3 -m tools.mdplus_builder verify-rom \
  --strict-regression build/sonic2-mdplus.md
```

`make rom` prepares fresh source itself; `make source` is optional for inspection.
The canonical production ROM is `build/sonic2-mdplus.md`. The local package is
`dist/Sonic 2 - Addryu Mega-CD Remix MD+/`, containing matching ROM/CUE basenames,
sixteen `trackNN.wav` files and `SHA256SUMS.json`.

Explicit legacy commands are:

```sh
make bootstrap-legacy
make source-legacy
make rom-legacy
python3 -m tools.mdplus_builder verify-rom --legacy \
  --strict-regression build/sonic2-legacy-mdplus.md
make package-legacy
```

`make rom-legacy` also prepares its own fresh source. Its output is
`build/sonic2-legacy-mdplus.md`. `make package-legacy` uses already prepared audio;
`make all-legacy INPUT_DIR="$PWD/inputs/audio"` runs the entire fallback build.
Legacy packaging replaces the same named Addryu package directory. The two ROM
build outputs coexist, and `make package` restores the production package.

Make delegates to `python3 -m tools.mdplus_builder`; the installed console entry
point is `sonic2-mdplus`. Canonical CLI commands are `bootstrap`, `prepare-source`,
`build-rom`, `prepare-audio`, `package`, `all` and `verify-rom`. Supply `--legacy`
to bootstrap, preparation, ROM building, packaging, full builds or verification
to select the fallback; audio preparation is shared.

The Make/CLI compatibility aliases `bootstrap-modern`, `prepare-modern` and
`build-modern` remain available. Production and alias builds write the canonical
ROM and create `build/sonic2-modern-mdplus.md` as a relative compatibility
symlink. `build-stock-modern` remains an independent untouched-upstream REV01
audit build in a disposable clone, producing `build/sonic2-stock-modern.md`.
That stock ROM has no MD+ support and is never selected for packaging.

## Hardware verification

The required Stage 5 MiSTer FPGA gate passed, as reported by the maintainer in
the [Stage 5 hardware record](../MODERN_STAGE5.md#mister-hardware-results).
Confirmed cases include:

- Normal boot and SEGA PCM; native title/menu BGM and SFX.
- Clean native-to-MD+ EHZ transition to Addryu track03, with no native level BGM
  leakage underneath MD+.
- Gameplay SFX during MD+, including jump, rings, spin dash, monitor, badnik hit,
  ring loss, checkpoint and Special Stage entry; no lost or corrupted effects.
- EHZ looping, Act 1 completion and Act 2 progression; CPZ MD+ playback.
- Pause/unpause during active MD+ without audible glitches.
- Speed Shoes accelerating physics while MD+ stays at normal speed.
- Extra-life native audio/MD+ interaction without audible problems.
- Special Stage entry, BGM, SFX and successful completion.
- MD+ level music to native invincibility and back to MD+.
- MD+ level music to native boss music and back in EHZ and CPZ.
- MD+ level music to native drowning music and back.
- Warm reset while MD+ is active; working level-select cheat.
- Death Egg MD+ to native Robotnik BGM for the Metal Sonic fight, back to
  Death Egg MD+, then native Final Boss BGM and the ending cinematic.

For Special Stage, static/source routing maps `MusID_SpecStage` to MD+ track29.
Hardware confirmed BGM, SFX and completion, but did not independently instrument
ownership/source identity. The audible observation does not establish a separate
native-audio attribution.

All sixteen Addryu cues and manifest loops retain their earlier hardware
verification. The optional missing-WAV robustness test was **not run**; no
missing-file outcome is inferred. The Stage 5 report did not supply a test date,
core version, region or package hash, and did not separately report every
extra-life path, pause during handoff, cold reset during active MD+, or separate
PAL/NTSC runs. No additional hardware coverage is claimed by this release pass.

## Upgrading from v1.0.0

Normal/default commands now produce the current-s2disasm ROM, so its generated
identity changes from the v1.0.0 legacy hash to the production hash above. Run
`make rom` after upgrading: strict packaging rejects an old legacy ROM left at
`build/sonic2-mdplus.md`.

Scripts expecting the legacy hash must use the explicit `*-legacy` Make targets
or CLI `--legacy` options and `build/sonic2-legacy-mdplus.md`. The legacy
implementation remains available for rollback.

The audio/CUE profile and sixteen Addryu soundtrack files remain unchanged,
including filenames, routing, loop coordinates, normalization policy and package
names. No new soundtrack purchase or audio conversion policy is introduced.
